# Jukie

An unofficial Apple Music client project, one platform at a time.

## Platforms

- [**webOS-legacy**](webOS-legacy) — Palm/HP webOS (TouchPad and Pre 3 era, 2011–2012
  hardware). The original and, for now, only Jukie. See its
  [README](webOS-legacy/com.achunt.jukie/README.md) for the technical details, the
  [feature tour](webOS-legacy/FEATURES.md) for a screenshot-by-screenshot look at what it
  can do, or the [release notes](webOS-legacy/RELEASE_NOTES.md) for a full summary of
  what went into it.

More platform variants are planned, which is why this repo is organized by platform
folder rather than assuming webOS is the only target.
